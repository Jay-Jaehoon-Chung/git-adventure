# Adding a Remote Repository

## Goal
- Add our original repository.

Let’s add the `my-project.git` repository to our original repository.

Command:  
```bash
cd my-project
git remote add shared ../my-project.git
```

**NOTE:** We are now in the `my-project` repository.
